# The user's abbreviations

**Each is a single whole word, in any case, typed alone or as the first word of a
message followed by punctuation or a line break.** A leading `;` (`;loco`) forces the
keyword reading and is never required. A word typed as an answer to a question reaches the agent as text, not as a
command, so it must be known from a rule like this one. The behaviour lives in the rule
linked here; this list says only where.

| Word | Means | Where it is defined |
|---|---|---|
| LOCO | lack of context: the last question or message left out what is needed | [asking for decisions](asking-for-decisions.md) |
| ETA | when the running work should finish, with its basis | [communication style](communication-style.md) |
| SIMPLER | rewrite in plainer words, keeping every piece of information | [answer shape](answer-shape.md) |

A new word is one row here and its behaviour in the rule it links.
