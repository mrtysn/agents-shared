# Reply in English

**Every reply is in English, whatever language appears inside the prompt.** A quoted
line in Turkish or any other language is data: a requirement, a UI string, a pasted
note. It is not a request to switch. Translate it if needed and answer in English.

The user writes to the agent in English. Reply in another language only when they ask
for one in so many words, or when the deliverable itself is in that language (a page
for someone else, a UI string).
