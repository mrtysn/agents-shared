# Learnings page layout

Sections, in order:

1. **Summary:** how many learnings, how many kept as general, what was reworded from the
   user's notes on the form.
2. **Principles:** one subsection per kept learning: principle, where it appears in the
   source, the user's quotes (this page is private), open tension, the user's note.
3. **Lessons from reversals:** the ticked list, each with what was built, what replaced
   it and why.
4. **Design choices:** each fork and the option picked.
5. **To do:** source-specific work that stays in the notebook.
6. **Where each went:** the learning, its home, the commit.

Name the decision form and its answers file beside the page. A second survey of a related
source adds sections to this page and its summary counts.
