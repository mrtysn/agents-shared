# Deepening techniques

Offer two or three that fit the moment, never the list. Run the one chosen: ask its prompts one
at a time, push on vague answers, and capture what comes out for the page. The user stays
generative here, so defer judgment until they say the space feels explored.

| Technique | Use when | Prompts |
|---|---|---|
| Verbs before nouns | The pitch is all setting and objects | Which verbs define the game? Which of them feel good alone? Build the mechanic from the verb; the nouns only support it. |
| Core loop brainstorm | The loop is fuzzy | What does the player do? What is the immediate reward? Why do it again? How does it change over time? |
| Player fantasy mining | The feeling is unclear | What fantasy does the player live out? What makes them feel powerful? What identity do they take on? |
| Genre mashup | The idea feels like every other game | Take two unrelated genres. How do they merge? What gameplay exists only in the merge? What is the hook? |
| Constraint as the game | There is too much to choose from | Pick one severe limit. What if it were the only mechanic? Build a whole game inside the limit. |
| Remix a known game | Fast raw material is needed | Pick a famous game. Change one fundamental rule. What follows from that single change? |
| Toy before game | The verb might not be satisfying | What is fun to mess with, with no goals? Play with it first. Which game appears on its own? |
| Failure state design | The stakes are flat | How can the player fail in an interesting way? What makes failure feel fair? How does it teach? How fast is the retry? |
| One button | The design is bloated | Only one button: what can it do? How does context change its meaning? Where does depth come from? |
| Anti-game | Every convention feels settled | Which rule would we break? What expectation can we subvert? Which anti-pattern becomes a feature? |
| Emergence | The design needs depth | Which simple rules combine? What comes out of the interaction? How might players surprise us? |
| Reward schedule | Retention is a worry | What is rewarded, and when? Fixed or variable? Intrinsic or extrinsic? Is the progression itself satisfying? |

Related techniques exist for story-led games (ludonarrative harmony, emotion targeting),
economies, meta-progression, multiplayer social dynamics and spectator value. Name them only
when the concept is clearly that kind of game, and write their prompts from the same shape:
four questions, each one a decision the user has to make.
