# Provenance: Paths the user has to navigate to are absolute

Why [the rule](../../claude/rules/absolute-paths-for-handoff.md) exists.

Asked for by hand at least five times across Aug 10–31: "full path of that file
please", "I need full path not this relative path", "either give me full path or
launch it yourself".

2026-10-25, homelab: told to run `notes-publish --audience public
2026-09-19-maybe-watch.html` "in a normal terminal", with no folder and no note
that the name was a document on the box. The rule said "outside the terminal",
which a second terminal window is not, so the wording excluded the case. A search
of 992 sessions from Sep 22 found one earlier relative-path command handed to a
terminal (`./install.sh`, 2026-09-25); the wording was widened to cover commands.
